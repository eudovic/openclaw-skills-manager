# App

This directory contains the Flask application, HTML templates, static assets, and helper scripts used by OpenClaw Skill Studio.

For public setup instructions, environment configuration, remote Docker compatibility notes, and contribution guidance, use the repository root README:

- [`../README.md`](../README.md)

## Quick local development

```bash
cd app
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python app.py
```
